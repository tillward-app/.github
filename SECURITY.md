# Security policy

If you think you have found a security problem in a Tillward app or on tillward.app, email [support@tillward.app](mailto:support@tillward.app) with "Security" in the subject. Include the app, the steps to reproduce it and what you expected to happen.

Please don't open a public issue, and don't test against a store you don't own. We reply as soon as we can and keep you posted until the fix ships. We don't run a paid bug bounty.

Merchants with a question about their own store data can write to the same address.
